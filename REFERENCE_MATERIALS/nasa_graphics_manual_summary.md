# NASA Graphics Standards Manual (NHB 1430.2, January 1976)

## Overview

Official NASA graphics standards manual establishing the visual communications system. Key era: the transition from "meatball" to "worm" logotype period.

---

## 1. Logotype

### The NASA "Worm" Logotype

- Letters N-A-S-A reduced to **simplified solid-stroke letterforms**
- **All strokes of uniform width** — evokes unity and technical precision
- **No cross-strokes in the two "A" letters** — imparts vertical thrust, unique contemporary character
- Must NEVER be altered, distorted, or re-drawn (only reproduced from official artwork)
- Always displayed **free-standing horizontally** on its baseline

### Incorrect Uses (DO NOT):

1. Letterforms broken by superimposed pattern
2. Placed within another solid shape (circle, box, etc.)
3. Outlined letterforms
4. Shadows projected from letterforms
5. Photographically distorted
6. Light benday screen against white background
7. Benday screen on dark background (must appear in white)
8. Shown on vertical axis (designed for horizontal baseline)

## 2. Colors

### NASA Red (Primary Accent)

- **Warm shade of red** — described as "very active color which brings a kinetic dimension"
- **4-color process formula: solid red + solid yellow**
- Use only when a second color is available and appropriate
- Intended for use only on **white or light-value neutral** backgrounds
- **DO NOT use with**: other bright saturated colors, medium-value colors, dark-value colors (dilutes effectiveness)

### NASA Warm Gray

- Secondary color for logotype and typography
- Used in: stationery version 2, signing applications

### Color Usage Rules

| Background         | Logotype Color                               |
| ------------------ | -------------------------------------------- |
| White              | NASA Red AND Black, Black, or NASA Warm Gray |
| Black or Very Dark | **White only**                               |
| Very Light Value   | Black                                        |
| Medium Value       | Black or White                               |
| NASA Red           | **White only**                               |

### General Color Philosophy

- Colors should NOT be pastel or faded
- **Bright primary and secondary colors** preferred
- **Middle-value range** for most applications
- Two-color standard for most NASA publications

## 3. Typography

### Primary Typeface: Helvetica

**Most important typeface family** in the NASA Unified Visual Communications System.

| Weight               | Use Case                                                         |
| -------------------- | ---------------------------------------------------------------- |
| **Helvetica Light**  | Body text, combined with logotype for fundamental identification |
| **Helvetica Medium** | Headings accompanying Light text settings                        |
| **Helvetica Bold**   | Alternative for headings in certain situations                   |

- Headings: **upper and lower case**
- Clean, contemporary sans-serif letterforms
- Extremely legible even at very small sizes
- Standard sizes: **10/11 pt (large), 7/8 pt (small)** for body typography

### Secondary Typeface: Futura

- **Futura Light** and **Futura Demibold** as alternatives
- Also used for headings

### Serif Alternatives

- **Garamond**: For publications of permanent nature, superior readability, old-style numerals
- **Times Roman**: For complicated problem-solving, large volume settings
- Headings may be set in Helvetica Medium or Times Roman Bold

### Typographic Hierarchy (Stationery Example)

- NASA logotype: **5/16" (0.79 em) cap height**
- Agency name: **10/11 pt Helvetica Light** upper and lower case (large typography)
- Small typography: **7/8 pt Helvetica Light**
- Postal indicia: **3/8" (1.9 em)**

## 4. Grid System

### Core Principles

- Grid is a **predetermined understructure** giving publications cohesive style
- Great organizer of material, saves execution time
- Brings **continuity** to diverse publications
- Applied to the **double-spread** — determines all margins, gutters, folio placement

### Grid Application Process

1. Analyze overall publication size and required information types
2. Apply grid to double-spread (margins, gutters, folios)
3. Block in elements: headlines, text columns, photographs, captions, folios
4. **Folio placement always in outside margins**

### Standard Grid Formats

**Leaflets & Folders (one-column recommended)**:

- Headings align at top, text/illustrations occupy major portion
- OR: Headings/text at top, photographs on separate track at bottom
- OR: Headlines/captions at top, text confined to bottom half

**Journals & Technical Publications (two-column recommended)**:

- Technical nature — use most of page space
- White bands for "breathing space"
- **Outline boxes around all technical diagrams**
- Rules to separate articles

**News Publications**:

- Two or three-column grids
- Bracket devices to isolate photographs/captions
- Photographs at top or bottom of page

### Cover-Interior Relationship

Three approaches for relating cover to interior grid:

1. Grid based on alignment with square image on front cover, headlines at top
2. All headlines and text "hanging" from top of page, photographs at bottom
3. Symmetrical center line from which text and photographs break up and down

## 5. Stationery Standards

### Letterhead & Envelope

- **Letterhead**: 8.5" x 11" (21.6 em x 27.9 em)
- **Envelope (#10)**: 4.5" x 9.5" (10.5 em x 24.1 em)
- Logotype cap height: **5/16" (0.79 em)**

### Large Envelopes

- Standard government sizes
- Logotype cap height: **5/16" (0.79 em)**
- Large typography: **10/11 pt Helvetica Light/Medium**
- Small typography: **7/8 pt Helvetica Light**
- Postal indicia: **3/8" (1.9 em)**
- Printed **black one color** on white or Kraft-colored stock

### Mailing Labels

- Size: **3" x 5" (7.6 em x 12.7 em)**
- Logotype cap height: **1/4" (0.64 em)**
- Large typography: **8/9 pt Helvetica Light/Medium**
- Small typography: **7/8 pt Helvetica Light**
- Camera reduced to **51% (78.5% of original)**

### Standard Color Schemes for Labels

1. Logotype in **NASA Red**, all typography in **black**
2. Logotype and all typography in **NASA Warm Gray**

## 6. Signage Principles

### Sign Design

- **Rectilinear** — avoid diagonal or curved elements
- High visibility typography
- **Consistent message formats** for uniform coordinated look
- Signs should be tested with **photostat mockups**

### Vehicle Identification

- Three color schemes:
  1. Black logo and typography on vehicles up to 40% gray value
  2. White logo and typography on darker than 40% gray
  3. NASA red with white or black typography for special vehicles

## 7. Key Visual Elements for UI/Dashboard Inspiration

### Geometric Principles

- **Rectilinear everything** — no border-radius
- **Uniform stroke widths** for text and lines
- **Grid-based layouts** with clear margins and gutters
- **Outline boxes** for grouping/diagrams

### Typography for Operational Interfaces

- **Monospace/data font** for numeric values (NASA uses Helvetica which reads well at small sizes)
- **Upper and lower case** for headings
- **Clear size hierarchy**: 10/11pt body, 7/8pt captions

### Color Application

- **NASA Red** = primary accent (kinetic, active, attention)
- **NASA Warm Gray** = secondary/neutral
- **White** = high contrast on dark backgrounds
- **Black** = primary on light backgrounds

### Spacing & Layout

- **Outside margins** for folios/annotations
- **Breathing space** (white bands) to relieve dense information
- **Clear column structure** for data alignment
- **Bracket/rule motifs** for grouping related elements

### The "Stem-Word" NASA Logotype

- Used in technical publications (Tech Briefs, etc.)
- Minimal, clean identification
- Single stroke letterforms

## Application to Vigil

### Integrating NASA SP-168 with EVA/NERV Aesthetic

The existing vigil aesthetic (NERV mission control + NASA 1970s identity guide) should emphasize:

1. **Color**: NASA Red as primary accent, warm gray scale, true black backgrounds
2. **Typography**: Clean sans-serif (consider switching to Helvetica or similar — currently using Share Tech Mono which is good for data but may need a sans for headers)
3. **Geometry**: All rectilinear, no curves, uniform stroke weights
4. **Grid**: Clear margin/gutter structure, breathing space between dense data sections
5. **Rules/Borders**: Thin 1px rules as dividers, bracket devices for grouping
6. **Logotype Style**: The simplified solid-stroke letterforms could inspire a simplified wordmark

### Suggested Enhancements

- Add NASA Red (#BA0C2F) as `accent` color in theme
- Add warm gray scale (`gray-100` through `gray-900` in warm tone)
- Consider geometric notched corners (like signage notches)
- Add bracket `[` `]` motifs for panel headers or data grouping
- Increase use of thin rules (1px lines) as section dividers
- Add "breathing space" / white band patterns between dense sections
